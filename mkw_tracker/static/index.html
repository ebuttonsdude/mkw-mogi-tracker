Name recognition guidance

Observed peak process VRAM was measured on an RTX 5090 with short, 12-name batches. It is not total GPU use or a guaranteed memory requirement. Leave memory for OBS and your desktop. Start with Qwen3-VL-4B GGUF Q4_K_M for broader GPU compatibility and a smaller download. A small paired check found similar name accuracy to NF4, not universal quality parity. NF4 remains a CUDA alternative; INT8, BF16 and NVFP4 also use NVIDIA CUDA. Qwen3-VL-4B GGUF uses Vulkan (AMD/Intel with compatible drivers) or CPU; install and select that backend explicitly. GGUF memory use and name accuracy are not the measured NVIDIA figures above. CPU inference can be slow. PaddleOCR and Tesseract also work without NVIDIA.

NVFP4 requires a supported NVIDIA Blackwell GPU and CUDA runtime (RTX 50-series SM120/121), not RTX 4070 or Radeon GPUs. RTX 5070 support does not guarantee enough free VRAM. Dismissing the hardware reminder is remembered for this browser and model; setup and runtime errors remain visible.

Experimental

YOLO mode

Automatically confirm future Mogi capture and imported results. Stop capture and finish imports before enabling. Disable at any time to return to manual review; already scored races stay scored. Missing slots or names become distinct not-detected-fixme players. Existing pending reviews are not confirmed.

External vision endpoint (optional)

Prefer a local/self-hosted vision model or a trusted second computer. The tracker never starts or stops this server. OpenAI-compatible does not always mean vision-capable. Automatic never selects this reader.

Only player name crops and a short transcription prompt are sent, not full frames, videos, sessions, scores or OBS credentials. Up to 12 sequential image requests per attempt; recognition can repeat, so paid cloud costs can grow quickly. HTTP is visible on the network. You manage the server, security, resources and availability. CPU/network inference may be slow; Unicode and symbols still need review.

Use a base URL ending /v1 or a full /chat/completions URL. Hostnames other than pinned localhost require HTTPS and explicit consent, even on a trusted LAN. TLS verifies the hostname; unsafe DNS peers are blocked. HTTP is limited to numeric loopback/private LAN addresses, or localhost (fixed to 127.0.0.1). HTTPS IP URLs require a certificate valid for the IP. URL/model edits clear consent and the saved key. Save first, then test with one random synthetic word image. No live capture is sent by Test.

Each request: 30 seconds, PNG at most 512×128 / 256 KiB, response body at most 16 KiB. Attempt: 300 seconds, no automatic retries. Stop capture or cancel the import to interrupt requests. Remote computation may continue after cancellation. Select External vision endpoint in Capture or Videos after configuring it. Normal Mogi mode still requires manual confirmation.
